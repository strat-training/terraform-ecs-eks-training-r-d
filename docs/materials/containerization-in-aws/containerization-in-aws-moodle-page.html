What this program is

Weeks 5–6 of the DevOps Bootcamp. In the local phase you ran the 3-tier task-manager app (React, Node.js/Express, PostgreSQL) on Minikube with Helm, GitLab CI, Argo CD and a full observability stack. This phase takes that same app to AWS in ap-southeast-1, with every piece of infrastructure written in Terraform. Requires the local phase to be complete.

Everyone starts with a shared AWS foundation — a VPC, Amazon ECR, Amazon RDS PostgreSQL and AWS Secrets Manager. Then you pick one track: Track A runs the app on Amazon ECS with Fargate, Track B runs it on Amazon EKS. Each track ends with a live capstone defense on Day 10.

Choose your track

Track A — Amazon ECS & Fargate

AWS-native containers with no servers to manage. Fargate Spot capacity, one Application Load Balancer, GitLab CI deploys, blue/green releases for the backend, CloudWatch logs and auto scaling, and scoped IAM task roles.

Track B — Amazon EKS

Kubernetes on AWS, carrying over your Helm and GitOps skills. One Spot node, IAM Roles for Service Accounts, External Secrets Operator, NGINX Ingress, Argo CD, Prometheus/Grafana and a Horizontal Pod Autoscaler.

Pass the Capstone Defense to complete this phase

Your facilitator reviews your repository, watches your system work live, and asks you to explain and fix things on the spot. Graded on Technical Execution (45%), Functional Demonstration (35%) and Presentation & Defense (20%), plus a pass/fail Documentation Gate. Pass with 75% or more and the gate met.

Suggested pace

One content pack every one to two days, five days a week, two weeks total. Build one module at a time and test each piece before moving on. Track B learners: keep your cluster running only while you work — about 3 hours a day.

The one rule

Destroy what you apply — every session. Cloud resources bill for every hour they exist, whether you're using them or not. End each session with terraform destroy in reverse order, and check that no load balancer is left running.
